# 代码范围

`verify_release.py`为本次公开文件整理编写的只读完整性核验脚本。它核对文件SHA-256，不运行研究分析。

[MODEL_CONFIGURATION.md](MODEL_CONFIGURATION.md)保留当前稿件S4中的模型设置和必要说明。这是配置文档，不是可以独立重跑研究的程序。

依照当前结果公开范围，本目录不混入MIMIC检索/筛选代码、历史研究指令、未采用分析、绝对本机路径或受限模型对象。没有用新写的示例算法冒充当年实际执行代码。
